# GPU Resource Manager

GPU Resource Manager 是面向共享 GPU 服务器的网页管理平台。用户可以查看 GPU 状态、创建和管理自己的容器，也可以通过智能助手用自然语言完成这些操作；平台管理员负责用户、镜像和资源维护。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| GPU 资源 | 查看 GPU 使用情况，按用户配额分配资源。 |
| 容器管理 | 创建、启动、停止和删除容器，查看连接信息；工作文件保存在容器的 `/workspace`。 |
| 镜像管理 | 用户选择自己的本地镜像预设；平台管理员负责拉取和删除本地镜像。 |
| 智能助手 | 用对话完成资源查询与容器操作，并展示工具执行结果。 |
| 运维监控 | 记录资源事件、清理结果和容量告警，供平台管理员查看。 |

平台提供传统手动模式和智能助手模式。登录后可在网页的「使用指南」中了解具体操作。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `backend/` | FastAPI 接口、权限校验、智能助手及 Docker/GPU 管理逻辑。 |
| `frontend/` | React 网页。 |
| `deploy/` | 服务与反向代理配置、部署脚本。 |
| `docs/deployment.md` | 依赖、配置、部署、更新及排障步骤。 |
| `.env.example` | 环境变量模板；实际配置保存在本地 `.env`。 |

## 部署与使用

部署前需要准备可用的 Docker、NVIDIA 驱动和 NVIDIA Container Toolkit。完整的依赖检查、配置方法及服务命令见 [部署与运维文档](docs/deployment.md)。部署完成后，用户通过网页注册或登录；平台账号与服务器的 Linux 账号是两套独立身份。

请勿将 `.env`、数据库、日志、私钥或 Superpowers 文档提交到仓库。
